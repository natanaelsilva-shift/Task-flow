# Taskflow - Sistema de Controle de Tarefas

Projeto desenvolvido em Angular para gerenciamento de tarefas.

## Funcionalidades

- Cadastrar tarefas
- Listar tarefas
- Editar tarefas
- Excluir tarefas
- Marcar como concluída
- Filtros por categoria, prioridade e status
- Busca por título ou descrição
- Dashboard com estatísticas
- Salvamento em localStorage

## Tecnologias

- Angular
- TypeScript
- HTML
- CSS
